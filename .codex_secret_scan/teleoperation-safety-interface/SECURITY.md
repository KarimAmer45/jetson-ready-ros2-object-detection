# Security Policy

## Scope

This repository contains a static browser prototype and documentation. It does not include robot firmware, backend services, authentication, or network command transport.

## Reporting a vulnerability

Open a private security advisory on GitHub if this project is hosted in a GitHub organization that supports advisories. Otherwise, open an issue with enough detail to reproduce the problem, avoiding sensitive operational data.

## Operational warning

Do not connect this prototype directly to a robot or vehicle. Treat all real command transport, authentication, authorization, logging, watchdogs, and safety enforcement as out of scope until they are implemented and reviewed separately.
